# 무림여록 — 도트 방치형 RPG 방향

사용자가 제공한 모바일 방치형 RPG 화면을 기준으로 화면 구성과 글꼴·정보 밀도를 바꾼다. 원본 게임의 캐릭터·아이콘·UI 이미지를 추출하거나 재사용하지 않는다.

## 현재 반영

- 기기 크기의 세로 화면: 웹의 큰 화면에서도 최대 480px 게임 프레임을 중앙에 배치
- 상단 협객 정보, 은전·내공, 체력·돌파 게이지
- 메뉴를 바꾸어도 유지되는 실제 전투 장면: 무협 협객·산적·대나무·이끼 낀 석문을 직접 작성한 픽셀 타일과 스프라이트로 표현
- 실제 공격·승리에 따른 검격·피해 수치·승리 표시, 움직임 감소 설정 지원
- AUTO 버튼으로 실제 전투 시작·중지, 습득한 무공 빠른 운용
- 현재 진행에 연결된 목표 표시, 실제 돌파 가능 시에만 알림 점 표시
- 캐릭터·무공·강호·도감·메뉴 하단 내비게이션
- 청회색 창, 대비가 있는 금색 제목·초록 행동 버튼, 각진 입체 테두리
- 앱에 포함한 Neo둥근모 한글 도트 폰트: 원격 폰트 CDN 없이 동작. 라이선스와 원본 출처는 `assets/fonts/`에 포함
- 무공 상세 창에서 실제 현재 능력치와 다음 강화 능력치 비교

게임 규칙과 저장 스키마는 그대로 유지한다. 기존 진행을 초기화하지 않는다. 시각 방향을 적용한 UI 기반 버전이며 이미지·캐릭터 종류·공격 프레임은 후속 작업에서 확장한다.

## 이후에도 지킬 기준

전투는 위쪽에 남기고, 아래 영역에서 성장·장비·무공을 관리한다. 글자를 작은 크기로만 줄이기보다 정보 위계와 짧은 설명으로 밀도를 맞춘다. 조작 영역은 기본 44px 이상을 유지한다. 스토어 출시 때 필요한 상점·광고·결제·뽑기는 실제 동작과 재화 정책을 구현한 뒤 노출한다.

사용자가 다시 제공한 무협 문서는 여전히 프록시 접속 제한으로 읽지 못했다. 원문을 확인하기 전에는 그 내용을 검토했다고 표현하지 않는다. 정확한 접근 결과는 `REFERENCES.md`에 기록한다.
