## 현재 구현에 적용한 범위

원문 내용을 확인하거나 반영했다고 주장하지 않는다. 첫 버전은 일반적인 무협 장르 관습인 수련·내공·경지 돌파·무공·강호 탐험을 바탕으로 독자적인 지역, 무공 설명, 짧은 기록 문구를 구성한다. 특정 작품의 인물, 서사, 고유 무공, 이미지, 문서 문장을 복사하지 않는다.

원문 검토를 이어가려면 환경 설정에서 `m.blog.naver.com`과 `namu.wiki`의 HTTPS 접근이 허용되어야 한다. 허용 후에도 사이트 자체의 접근 제한이 있을 수 있으므로 실제 응답을 다시 확인한다. 네트워크 제한은 우회하지 않는다.

추후 본문에 접근하면 사용할 개념을 원문과 대조하고, 외부 문장이나 이미지 등을 직접 이용하려는 경우 해당 자료의 이용 조건과 출처 표시를 별도로 확인한다.
