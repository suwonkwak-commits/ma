# 금자·천옥과 환생 경제

## 재화의 역할

| 재화 | 역할 | 현재 획득 경로 | 표현 |
| --- | --- | --- | --- |
| 금자 | 한 생의 수련·무공 강화에 사용하는 일반 재화 | 전투 승리 | 가운데 네모난 구멍이 있는 금빛 도트 동전. 기존 아이콘의 표시 크기 유지 |
| 천옥(天玉) | 환생 뒤에도 남는 상위 재화. 향후 유료 상품과 연결할 후보 | 화경 이상에서 환생 | 금자와 구별되는 청백빛 옥 원석 |

사용자가 선택한 이름은 **천옥 — 하늘의 기운을 담은 옥**이다. 선옥·영옥보다 상위 재화라는 인상이 명확하고, 환생으로 축적하는 기운과도 어울린다. 현재 구현되는 천옥은 플레이로 얻는 재화이며 실제 결제·가격·충전 상품은 아직 없다.

## 경지와 환생 조건

삼류 → 이류 → 일류 → 절정 → 초절정 → **화경(化境)** → 현경(玄境) → 생사경(生死境) → 자연경(自然境).

환생은 현재 생에서 **화경에 도달한 이후** 가능하다. 이전 생의 최고 경지가 화경이었다는 기록만으로 새 생에서 즉시 다시 환생할 수는 없다. 환생 전에 예상 천옥과 초기화·보존 항목을 보여 주고, 별도 확인을 받아 실행한다.

## 현재 환산식

계산에는 보유 잔액 대신 **이번 생에서 획득한 누적 내공·금자**를 쓴다. 돌파와 무공 강화에 이미 사용한 자원도 인정해, 성장에 투자한 사람이 손해 보지 않도록 한다. 새 출발 지원금 150금자는 누적 획득 금자에서 제외한다.

| 구성 | 천옥 환산 |
| --- | --- |
| 도달 경지 | 화경 20 / 현경 30 / 생사경 50 / 자연경 80 |
| 이번 생 누적 획득 내공 | `내림(√(내공 ÷ 100))` |
| 이번 생 누적 획득 금자 | `내림(√(금자 ÷ 10))` |
| 이번 생 공적 | `내림(공적 ÷ 10)` |

네 항목을 더한 정수가 환생 보상이다. 공적은 현재 전투 승리 1회당 1, 경지 돌파 1회당 10을 얻는다. 수동 수련·자동 수련·오프라인 수련·전투의 실제 획득량이 누적 내공에 포함된다.

예를 들어 화경, 누적 내공 23,200, 누적 금자 350, 공적 70이면 `20 + 15 + 5 + 7 = 47천옥`을 얻는다. 기존에 11천옥을 보유했다면 환생 후 58천옥이 된다.

이 수치는 첫 환생 흐름을 검증하기 위한 초기 밸런스다. 실제 플레이 시간과 재방문 데이터를 확인한 뒤 조정한다.

## 환생 후 상태

| 새로 시작하는 것 | 보존하는 것 |
| --- | --- |
| 삼류, 내공 0, 새 출발 지원금 150금자 | 기존 천옥과 이번 환생 보상 |
| 기초 청무검법 1성, 나머지 무공 미수련 | 환생 횟수와 누적 획득 천옥 |
| 첫 지역, 안전한 수련 상태, 기본 체력 | 협객 이름과 최고 도달 경지 |
| 이번 생의 승리·패배·공적·누적 획득량 | 평생 누적 승리와 수행 기록 |

보상으로 전환한 생의 자원·공적은 새 생에서 다시 환산하지 않는다. 환생을 연속 확인하거나 저장을 다시 불러오는 것으로 같은 보상을 중복 지급하지 않는다. 메뉴의 전체 기록 초기화는 환생과 별개이며, 천옥과 환생 기록까지 지우는 동작임을 명시한다.

이전 저장 버전에는 누적 획득량이 없으므로, 남은 내공과 확인 가능한 돌파 소모량, 남은 일반 재화와 확인 가능한 무공 강화 소모량을 기준으로 이관한다. 정확한 과거 전체 획득 기록을 복원했다고 표현하지 않는다.

## 천옥의 추천 사용처

1. **외형:** 의복·검집·무기 잔상·수련장 테마. 구매 결과를 미리 볼 수 있고 오래 소유할 이유가 있는 상품부터 만든다.
2. **제한된 편의:** 무공 운용 구성 저장 칸, 수련 예약 같은 기능. 기본 플레이가 충분히 가능하도록 무료 범위와 상한을 먼저 정한다.
3. **꾸준한 수집:** 정해진 구성의 외형 묶음이나 시즌 장식. 첫 출시에서 유료 확률형 뽑기를 핵심 성장 조건으로 만들지 않는다.

현재는 위 사용처와 상점을 구현하지 않았다. 무공·경지의 기본 진행은 금자와 내공으로 수행하며, 환생 자격을 유료 구매로 막지 않는다. 우선 첫 환생까지 걸리는 시간, 환생 후 재성장 속도, 다음날 재방문, 무료 천옥 수급과 소비 의향을 검증한다.

## 출시 전 검증할 균형과 신뢰성

- 자원 환산의 제곱근은 장시간 방치 자원의 급격한 팽창을 완화한다. 반면 공적은 선형이므로, 약한 적을 빠르게 반복 처치하는 방식이 보상을 독점하지 않는지 확인해야 한다. 지역 난이도 가중치나 공적 환산 상한은 이후 밸런스 후보이며 현재 적용된 규칙은 아니다.
- 실제 결제를 도입할 때는 획득 천옥과 유료 충전 천옥의 원장을 서버에서 구분하고, 결제 검증·중복 요청·환불·구매 복원·소비 순서를 함께 설계한다. 지금의 로컬 천옥 잔액을 결제 증빙으로 사용하지 않는다.
- 현재 저장 검증과 중복 지급 방지는 개발 버전의 정상 플레이 흐름을 위한 것이다. 기기 시간이나 로컬 저장을 조작할 수 없다고 보장하지 않는다. 결제·경쟁 기능을 도입하기 전 서버가 보상과 거래를 확정해야 한다.
